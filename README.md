# Nisconder的GKD订阅

一份 GKD 规则订阅，用于按需处理开屏广告和广告弹窗。

把下面地址复制到 **GKD → 订阅 → ＋** 中添加，再按需开启规则，以后在 GKD 中更新即可。

```text
https://nisconder.pages.dev/gkd/subscription.json5
```

添加说明和备用地址见[博客获取页](https://nisconder.pages.dev/gkd/)。

查看[更新历史](https://nisconder.pages.dev/gkd/#updates)，或提交[问题反馈](https://github.com/nisconder/Nisconder-GKD-Subscription/issues)；反馈时请附上应用版本和复现步骤。

规则基于 Lin-arm id667 v632，[查看规则来源与原声明](https://github.com/Lin-arm/GKD_subscription/blob/6b8c9848bd35ff11fd14120b156dc3d16c98e8a1/README.md)。
