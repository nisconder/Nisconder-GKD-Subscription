## 添加订阅

将下面的完整地址复制到 **GKD 订阅页 `+`**，确认添加后按需启用订阅和规则组：

```text
https://nisconder.pages.dev/gkd/subscription.json5
```

GitHub Raw 备用直链：

```text
https://raw.githubusercontent.com/nisconder/gkd-subscription/main/dist/gkd.json5
```

版本检查文件由 GKD 使用，不要把它当作完整订阅导入：

```text
https://nisconder.pages.dev/gkd/version.json5
```

此处提供的是普通 HTTPS 订阅地址，不是自动导入深链。GKD 1.13.1/1.13.2 的 `gkd://page` 仅用于打开应用页面。

已经安装同 ID 订阅的用户不要重复添加或删除现有订阅来重置配置。尤其是通过 ZIP 创建、尚无更新链接的订阅，仅修改规则正文中的 `updateUrl` 不保证完成远程地址绑定；应先保留备份，再单独核验更新链接及自动更新开关。

## 默认范围与已验证边界

分类默认只开启开屏广告，其他分类按需开启；具体规则的原有默认值和用户已保存的设置仍会参与判断。已收录不等于已启用，也不等于已验证。

全局范围取既有允许集合与本仓库公开支持应用清单的交集，保持 `matchAnyApp:false`。三个全局组分别默认允许 45、46、34 个应用参与范围判断，合并去重为 47 个应用；这不是成功适配数量。未列入的包默认不匹配，系统或桌面代理也不会因为存在专用规则就自动加入全局范围。个人 `matchAnyApp` 覆盖、强制开启及其他排除设置仍可能改变实际范围。

| 全局组 | 默认开关 / 范围 | 控件与排除条件 | 验证边界 |
| --- | --- | --- | --- |
| 开屏广告 `0` | 开 / 45 个应用 | 仅明确 SDK 跳过 ID，或同一 splash 内广告跳转文案与相邻倒计时；切入应用 8 秒内最多一次，明确协议同意弹窗停止匹配 | 泛化界面不覆盖；全局自动效果仍待对应应用真实正例验证 |
| 更新提示 `1` | 关 / 46 个应用 | 仅同一原生对话框的明确更新标题及精确“稍后”等按钮，排除强制更新 | 自绘或网页弹窗不覆盖；待真实正例与自动关闭验证后按需开启 |
| 青少年提醒 `2` | 关 / 34 个应用 | 仅原生信息提醒中的精确“知道了”等按钮，排除年龄声明、监护、密码及模式开关内容 | 不修改年龄或保护模式；待真实正例与自动确认验证后按需开启 |

同一订阅已有对应名称前缀的专用规则组时，全局组会被抑制；专用组关闭并不自动让全局规则接管。应用规则的成功证据也不计作全局规则已验证。

拼多多的新分支对已识别控件执行 `clickCenter`，坐标来自控件当前边界，不保存固定屏幕位置。旧两条可点击分支仍使用 `clickNode`。X 的旧版详情规则继续保留版本隔离；原生自动翻译偏好与本订阅的可选功能开关是不同设置。

微信、音乐、闲鱼等修订经过相应历史快照或合成边界回归，但这些证据不等同于当前所有版本的自动执行验证。未出现目标、只匹配到选择器或只有动作日志，都不能直接记为功能成功。

## 本地构建

使用 Python 3.10 或以上，在仓库目录运行：

```sh
python tools/build.py
python -m unittest discover -s tests -v
```

构建只使用 Python 标准库，不联网、不访问手机，也不需要 `device/` 目录。源码入口为：

- `config.json`：名称、ID、版本与发布 URL。
- `categories.json`：分类默认值。
- `rules/apps/`：公开支持应用的规则。
- `rules/global-groups.json`：全局规则、共享条件和公开范围表。

产物为 `dist/gkd.json5`、`dist/gkd.version.json5` 和 `dist/release.json`。发布配置中，前两份文件分别对应 `/gkd/subscription.json5` 和 `/gkd/version.json5`；`release.json` 记录计数与文件摘要。构建命令本身不会发布网站或推送仓库。

仓库 CI 在 `main` 推送及 Pull Request 中运行构建、测试和产物一致性检查，`v` 开头的版本标签用于生成 GitHub Release。网站镜像每半小时获取最新 `main` 的固定提交，校验 `release.json` 中的文件摘要后再发布；提交与镜像更新之间可能存在同步延迟。

修改规则时保留需要延续的应用、组和规则身份，递增版本后重建。生成文件不宜直接编辑。当前公共树不包含设备安装清单、备份、调试记录、私人测试时间或快照链接。
